# Employee Management System

A simple Employee Management application built using ASP.NET Core MVC.

## Features
- Create Employee
- View Employee List
- Edit Employee
- Delete Employee
- Form validation
- Error handling
- Async operations

## Tech Stack
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- Razor Views

## How to Run
1. Clone the repository
2. Open in Visual Studio
3. Update database connection if needed
4. Run the project
